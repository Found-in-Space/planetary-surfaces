# Blue Marble: July 2004

Build the cloudless, unshaded NASA Blue Marble: Next Generation **Base Map**
from all eight full-resolution 500 m RGB GeoTIFF sheets. This recipe deliberately
selects one fixed month. It does not mix seasons or add relief, clouds or
bathymetry. Its data period differs from the Black Marble 2016 companion.

See the [paired Earth workflow](../README.md) for source admission, durable
storage, full-pyramid commands, disk budget, credits and S3 publication handoff.
The checked-in acquisition specifications pin the complete source files and
SHA-256 checksums admitted after acquisition and review on 17 October 2026.
